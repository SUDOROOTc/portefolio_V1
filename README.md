# Portfolio V1 🚀

Portfolio professionnel moderne créé pour présenter mes compétences et projets de développement web.

## 📋 Description

Ce portfolio est un site web responsive et moderne qui présente :
- **Accueil** : Page d'accueil avec introduction
- **À Propos** : Présentation personnelle et parcours
- **Compétences** : Liste des technologies et outils maîtrisés
- **Projets** : Showcase de projets réalisés
- **Contact** : Formulaire de contact et informations

## 🛠️ Technologies Utilisées

- **HTML5** : Structure sémantique du site
- **CSS3** : Styles et animations modernes
- **JavaScript** : Interactivité et animations dynamiques

## ✨ Fonctionnalités

- ✅ Design responsive (mobile, tablette, desktop)
- ✅ Navigation fluide avec smooth scrolling
- ✅ Animations au scroll
- ✅ Menu hamburger pour mobile
- ✅ Formulaire de contact
- ✅ Sections interactives
- ✅ Design moderne et professionnel

## 🚀 Installation et Utilisation

### Option 1 : Ouvrir directement
1. Cloner le repository
```bash
git clone https://github.com/SUDOROOTc/portefolio_V1.git
cd portefolio_V1
```

2. Ouvrir `index.html` dans votre navigateur

### Option 2 : Serveur local
```bash
# Avec Python
python -m http.server 8000

# Avec Node.js (http-server)
npx http-server
```

Puis ouvrir http://localhost:8000 dans votre navigateur

## 📱 Responsive Design

Le portfolio est optimisé pour tous les écrans :
- 📱 Mobile (< 480px)
- 📱 Tablette (481px - 768px)
- 💻 Desktop (> 768px)

## 🎨 Personnalisation

Pour personnaliser le portfolio :

1. **Contenu** : Modifier le texte dans `index.html`
2. **Couleurs** : Ajuster les variables CSS dans `styles.css`
3. **Fonctionnalités** : Modifier le comportement dans `script.js`

### Variables CSS principales
```css
--primary-color: #3498db;
--secondary-color: #2c3e50;
--accent-color: #e74c3c;
```
